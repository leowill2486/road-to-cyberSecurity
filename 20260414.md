Today, I explored the core principles of virtualization, which allows a single physical machine to act as multiple independent computers by sharing its hardware resources. I learned about the Hypervisor, the essential software that manages these resources, and identified the critical difference between its two types: Type 1 runs directly on the bare-metal hardware for maximum performance, while Type 2 runs as an application on top of an existing operating system for ease of use in personal labs. Additionally, I touched on containerization as an efficient way to host multiple small applications by sharing the host's operating system. Ultimately, I found that these technologies provide significant benefits like cost savings, better resource utilization, and scalable, safe environments for cybersecurity testing and application deployment.
